# Police Out — Store Assets (itch.io & APKPure)

This folder contains genuine in-app store visuals captured directly from **Police Out** for **itch.io** and **APKPure** (kept outside `public/` and `src/` so they do not bloat the APK size).

## Files Included
- `police_out_icon.jpg` — Official Police Out game icon / cover logo (`1024×1024` JPEG).
- `feature_graphic_1024x500.jpg` — APKPure / Google Play Feature Graphic (`1024×500` JPEG, 24-bit, no alpha).
- `screenshots/01_home_screen.jpg` — Organized Start Home Screen (`1080×1920` JPEG, ratio ≤ 2:1).
- `screenshots/02_gameplay_classic.jpg` — Classic 6×6 Parking Puzzle Board (`1080×1920` JPEG).
- `screenshots/03_gameplay_night_patrol.jpg` — Night Patrol theme gameplay (`1080×1920` JPEG).
- `screenshots/04_themes_gallery.jpg` — 8 Board Themes selector (`1080×1920` JPEG).
- `screenshots/05_all_stages.jpg` — All 360 Stages grid (`1080×1920` JPEG).
